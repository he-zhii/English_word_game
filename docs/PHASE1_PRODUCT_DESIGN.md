# 第一阶段产品设计：自主选词与宠物陪伴

状态：当前首版设计基线，待实现。  
适用设备：手机、平板，竖屏优先。  
本稿取代 `PRODUCT_DESIGN_V2.md` 中的首版范围；旧稿保留为历史讨论资料。

## 1. 核心定位

孩子用自己选择的宠物和词表，轻松练习课本单词。单词既可以来自预习，也可以来自课堂学习；产品负责帮助孩子进一步熟悉和巩固拼写，并提供发音支持。

首版关注自主选择、操作简单和完成后的积极反馈。家长无需设置每日任务、教学解锁、学习目标或报告参数。选择教材后，孩子能够自己完成日常使用。

首版闭环：

选择单元或勾选单词 → 完成本次拼写练习 → 获得宠物反馈 → 自主继续、回首页或选择 5 / 10 词大乱斗。

## 2. 已确认与首版实施建议

### 已确认需求

- 按单元组织内容，孩子自由选择，用于预习与巩固。
- 提供方便的本次词表勾选操作。
- 大乱斗每次 5 / 10 词，从已学范围抽取。
- 宠物可以自定义，承担陪伴和完成后的反馈。
- 首页显示宠物；专注作答期间隐藏；完成后可以做动作或姿态回应。
- 学习报告和较重的家长功能留到第二阶段再讨论。

### 本稿建议的具体取舍

- 六单元直接展示并可选择，不增加剧情地图、关卡解锁或每日任务。
- 自定义先支持选择基础外形、配色与名字；更复杂的自由绘制、AI 生成和养成规则留后。
- 学习采用一个拼写流程，保留点读、提示、修改和重试，不增加多个阶段入口。
- 普通练习词数由孩子选定的词表决定；5 / 10 的限制只用于大乱斗。
- 首版奖励采用短动作、具体鼓励和一组完成后的庆祝；等级、经验经济、进化与商店暂缓。
- 一次练习的勾选不修改教材原始词表，也不等于删除或停用单词。

## 3. 页面结构

首版只设置首页、词表选择面板、练习页和结算面板。自定义宠物与大乱斗设置使用轻量面板，不另建营地、挑战地图或报告中心。

| 位置 | 内容 | 主要操作 |
| --- | --- | --- |
| 首页 | 当前课本、自己的宠物、六个单元、大乱斗入口、未完成练习入口 | 选单元、继续练习、摸摸或编辑宠物 |
| 词表面板 | 当前单元的英文与中文、复选框、已选数量 | 全选、取消全选、逐词勾选、开始 |
| 练习页 | 题面、发音、答案区域、字母输入、提示、已完成数量 | 拼写、修改、提交、下一题、保存退出 |
| 结算面板 | 本次实际完成数量、宠物动作、简短反馈 | 回首页、再练本组选词 |

首屏让孩子看见自己的宠物和可选单元。宠物区域保持紧凑，避免将单元入口推到很远的位置。教学内容入口不依赖阅读长说明。

课本选择保留在首页；默认记住上次册次。所有单元可以预习、练习、重练，无家长解锁步骤。

## 4. 单元与快速勾选

点击单元后打开词表面板，默认选中该单元全部词。孩子可直接开始，也可取消部分词；再次打开可以恢复上次选择，并明确显示当前勾选数量。

- 单词行显示英文与中文，整行便于触控勾选。
- 提供全选、取消全选和已选数量。
- 选中至少一个词才能开始；零词时给出简短提示。
- 选择一个词也能练，普通单元练习没有最低词数。
- “快速选词”复用同一个面板，可切换单元并保留已勾选项，用于跨单元自选。
- 所有单元默认可进入，不因未练过前面的内容而限制。
- 本次选择与默认教材内容分开保存，不影响以后重新全选。
- 练习过程中不自动增加孩子未选的词，结束后不自动启动另一轮。

词表选择本来就展示英文，因此不能把紧接着一次答对宣称为长期掌握；首版不输出这类学习评价。

## 5. 拼写练习

### 单一流程

题面展示中文和合适的图片/情境，提供发音。孩子通过屏幕字母键盘拼写，提交后获得结果。完整英文答案在求助或完成后展示。

手机和平板使用固定位置的 A–Z 全字母键盘，提供退格、修改和提交。重听发音不限次数；首次使用用短提示说明操作，不要求家长教学。

- 简单词、长词和词组都由当前题面清楚展示输入区域；长词不任意拆行。
- 需要帮助时，可补出一个字母，或查看范例后再次尝试。
- 错误提交后说明具体差异，允许就地修改；不扣分、不要求从本组第一题重来。
- 提交之前自己修改不算一次错误。
- 答对后展示完整词并可播放读音，孩子点击“下一题”。
- 每题可先放一放；暂放不算完成，会出现在本组结算的未完成数量中，孩子可选择以后再练。
- 题目顶部显示“第 2 / 8 个词”一类实际进度。
- 中途退出保存已选词表、当前进度和已确定结果；回来可以继续。

帮助完成同样算一次练习，可以进入默认大乱斗词池。首版只记录练过事实，不将提示次数转换为能力报告。

### 发音

首次主动操作后启用播放，避免页面一打开就强制出声。支持重听，声音设置简单且实际生效。

题目发音与宠物反馈音效避免叠加。已加载页面音频失败时，以中文或情境继续拼写；不把音频失败当成答错，也不因此宣称具备完整离线能力。

## 6. 宠物出现的时机

将“首页陪伴”和“正在答题”分成不同状态，以落实用户希望作答时不出现宠物的要求。

| 时机 | 是否显示 | 行为 |
| --- | --- | --- |
| 首页选单元、等待开始 | 显示 | 安静待着；点击可以回应 |
| 正在输入、修改、求助、重试 | 隐藏 | 不占题面，不播放宠物动作 |
| 单题已经正确完成 | 短暂显示 | 点头、拍手、挥爪等；与结果同一区域呈现 |
| 点击下一题 | 隐藏 | 立即进入下一题作答 |
| 本组完成 | 显示 | 一次更完整但可跳过的庆祝 |
| 中途保存退出 | 首页恢复显示 | 平静欢迎，不表现失望或扣成长 |

单题反馈是首版建议：约一秒的短动作，不另弹模态窗口，也不强制等待动画结束才能下一题。真正作答和纠错过程中保持宠物隐藏。

文案示例：“拼出来啦！”、“这个词我们一起记住了。”后一句只作为伙伴表达，界面不据此标记长期掌握。更推荐具体表述，如“这次把两个 p 都拼上了”。

### 自定义范围

- 从少量基础外形中选择一个，例如猫、狗、小龙，最终数量和美术在原型时确定。
- 选择配色、取名，首页点击宠物可再次编辑。
- 保存的是一只当前伙伴，不设置多宠物收集和重复养育。
- 不设置饥饿扣减、每日签到损失、生命值或宠物战力。
- 首版先制作待机、单题完成、整组完成三类主要动作，控制资源规模。

## 7. 大乱斗

入口只有词数选择和本次范围，不增加计时、难度等级、剧情或排行榜。

### 词数

- 默认 5 词，可选 10 词。
- 从本次有效范围随机抽取不同词，不重复凑数。
- 范围不足 10 词时不能选 10；不足 5 词时可提供实际数量的热身。
- 范围为空时提示先练一组，或去勾选自己已经学过的词。

### 已学范围

默认使用当前课本中在游戏里完成过一次有效拼写练习的词。只是浏览词卡、点读或勾选，不自动生成“练过”的记录。

考虑到孩子可能已经在课堂学过，但尚未在游戏练过：通过“调整范围”复用词表面板，允许孩子手动勾选这些词参加本次大乱斗。面板说明“选择你已经学过、这次想挑战的词”。

手动选择决定本次挑战范围，不自动标成游戏练过或已掌握。实际完成拼写后，再加入默认练过词池。界面记住上次范围选择，始终明确显示本次范围与词数，避免隐藏规则。

首版不跨册混题；跨单元选择允许。相同拼写且练习目标一致的词在一局中去重。

### 局内和结算

- 与普通练习共用题面、输入、提示、修改和宠物反馈。
- 显示第几个词，不倒计时、不掉血。
- 允许保存退出、暂放困难词；结算按实际完成数量展示。
- 不用满分限制下一次挑战；不会自动开始新的大乱斗。
- 普通单元练习和大乱斗只在选词方式上不同，不各自形成一套宠物或奖励规则。

## 8. 最少设置与数据

孩子日常只需选单元/选词、设置宠物，必要时开关声音。家长不需要维护学习日程、课程开放和学习报告。

首版仍需可靠保存以下基础数据，主要服务孩子自己的体验：

- 上次课本、单元与选择范围。
- 宠物外形、配色、名字。
- 在游戏实际练过的词，用于大乱斗。
- 本组词表、当前题目、答案草稿和完成状态，用于恢复。
- 声音设置。

这些记录不构成学习报告，也不据此推断“已经掌握”。若第二阶段需要更详细分析，应重新确认数据口径。

本地保存为首版基线；手机和平板之间不会自动同步。同步、备份界面、多个孩子档案等后续按需要安排，不作为孩子首次开始练习的前置步骤。

## 9. 第一阶段与后续范围

| 第一阶段实现 | 第二阶段及以后再讨论 |
| --- | --- |
| 单元自由选择 | 连续剧情地图、任务系统 |
| 快速勾选本次词表 | 学习报告、家长分析 |
| 一个清楚的拼写流程 | 自动安排复习、复杂自适应阶梯 |
| 点读、帮助、修改、继续 | 口语评分 |
| 5 / 10 词大乱斗 | 排行榜、其他挑战变体 |
| 自定义一只宠物 | 多宠物养成、等级进化、商店 |
| 首页陪伴与完成反馈 | 大规模装饰收集或故事演出 |
| 基础本地保存与恢复 | 跨设备同步、多个孩子档案 |

右栏是候选方向，并非自动进入第二阶段的承诺。学习报告可以优先在第二阶段讨论，是否需要其他内容由实际试用决定。

## 10. 开发与验收

先打通“单元/勾词 → 作答 → 结算 → 恢复”，再接入练过词池与 5 / 10 词大乱斗，最后加入宠物自定义、首页陪伴和完成反馈。各步使用同一套移动端输入与保存规则。

| 检查场景 | 合格表现 |
| --- | --- |
| 孩子第一次进入 | 选课本和宠物后能开始；没有家长任务配置 |
| 点击任一单元 | 可以直接选词练习，不要求前面单元通关 |
| 快速勾选 3 个词 | 本组只练这 3 个，教材其他词不被删除 |
| 选择 0 个词 | 不进入空白练习，提示选择至少一个 |
| 正在输入或改错 | 宠物完全隐藏，声音和动画不干扰 |
| 单题完成后继续 | 宠物短暂反馈；下一题立即隐藏，无强制等待 |
| 本组结束 | 展示实际完成数量和宠物庆祝，可自然回首页 |
| 请求帮助后完成 | 允许进入练过词池，不虚报独立掌握 |
| 手动选择课内已学词挑战 | 可参加本次挑战；选择本身不生成游戏练习记录 |
| 选择 5 / 10 词 | 数量和当前范围一致，无重复凑数、无隐性新词 |
| 刷新、退出、旋转 | 进度保存，恢复时不重算已完成结果 |
| 手机或平板使用 | 能清楚点中字母、改字、提交，控件不被遮挡 |

首版体验判断：孩子能否自己开始、自己选词、遇到困难后继续，以及是否喜欢自己定制的伙伴和完成后的反馈。实际记忆效果可通过少量隔日重练观察，无需先建设报告系统。
