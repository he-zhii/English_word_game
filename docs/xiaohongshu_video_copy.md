# 糯米单词屋 · 小红书宣传视频文案方案

> 产品基线：小学 1-6 年级英语单词拼写练习工具，按人教 PEP 课本册次/单元组织词表，支持萌宠陪伴、点读发音、自选单词、5/10 词大乱斗。

---

## 一、核心设计：怎么表达"帮助小孩更好地学习同步课本"

### 推荐主定位语（按使用场景选）

| 风格 | 文案 |
|------|------|
| **最直接** | 课本学到哪，单词拼到哪。 |
| **结果导向** | 当天学的单词，当天就能自己拼出来。 |
| **家长视角** | 把课本单词表，变成孩子愿意打开的练习游戏。 |
| **孩子视角** | 带上你的宠物，把课本单词一个个拼通关。 |
| **信任感** | 按人教版课本单元走，课堂单词一个不落下。 |

### 视频里可以怎么讲

- 不要说："帮助小孩更好地学习同步课本。"
- 改说："三年级上册 Unit 1 刚学完？打开这个单元，课堂上见过的单词都在这里，拼一遍就记得更牢。"
- 改说："不用家长一个字一个字教，孩子自己跟着课本进度练。"

## 二、目标人群：精准切入与痛点触达

### 主要目标人群

1. **小学家长（妈妈为主）**：孩子正在学英语，家长辅导吃力或没时间。
2. **小学中高年级学生**：开始接触单词拼写，对游戏化学习接受度高。
3. **关注学习工具的老师/教育博主**：寻找可推荐给学生家长的工具。

## 三、亮点展示：游戏里该展示什么、配什么文案

### 1. 课本同步 · 按单元选词

**展示画面**：首页切换课本（三上/三下/四上…）→ 点击单元 → 进入词表勾选。

**口播文案**：
> "三年级上册第一单元，课堂上刚学过的单词都在这里。想练几个勾几个，不用从头刷。"

### 2. 萌宠陪伴 · 自定义小伙伴

**展示画面**：首页宠物待机 → 点击编辑换颜色/外形/取名字 → 完成练习后宠物做庆祝动作。

**口播文案**：
> "孩子先挑一只自己的宠物小伙伴，拼对一个，它就给他鼓掌。"

### 3. 拼写流程 · 点读+提示+改错

**展示画面**：题目出现中文/图片 → 点喇叭听发音 → 屏幕键盘输入字母 → 错误后提示差异 → 再次提交正确。

**口播文案**：
> "不会拼？先听一遍。卡住了？点提示出一个字母。拼错了也不会重头来，改对了继续走。"

### 4. 5/10 词大乱斗 · 随机挑战

**展示画面**：选择"大乱斗" → 勾选已学范围 → 开始快速挑战。

**口播文案**：
> "学过的单词还能进大乱斗，5 个 10 个随机抽，像闯关一样复习。"

### 5. 进度自动保存 · 随时回来继续

**展示画面**：练习到一半退出 → 重新打开 → 弹窗"是否继续上次练习"。

**口播文案**：
> "练到一半被打断也没关系，下次打开接着练。"
