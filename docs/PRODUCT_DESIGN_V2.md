# 糯米单词屋 V2：移动端产品设计

状态：历史讨论稿，尚未实现；首版范围已由 [第一阶段产品设计](./PHASE1_PRODUCT_DESIGN.md) 取代。以下地图、任务、养成、报告等较完整方案仅保留作后续参考，不作为当前首版开发要求。  
主要设备：手机、平板；竖屏优先，兼容横屏。  
核心目标：让孩子愿意主动练习课本单词，并逐步能够在没有拼写答案提示时独立拼出，隔日仍能回忆。

## 1. 已确认需求与设计边界

### 用户已确认

- 可以大幅调整现有产品设计。
- 以同步课本单词为内容范围，主要训练拼写，发音贯穿学习。
- 关注孩子的兴趣、主动选择、轻松完成和真实记忆效果。
- 接受从几只小宠物中选择伙伴，共同成长的轻量养成方式。
- 六个单元形成一张连贯地图，并能按学校教学进度直接开放。
- 大乱斗改为 5 / 10 词；练过的词即可进入挑战词池。
- 手机和平板是主要使用设备。

### 本稿提出的首版方案

- 三选一伙伴、每种三个成长阶段，规则一致，外观和表达有区别。
- 儿童端三个主要入口：冒险地图、伙伴营地、挑战场；单词图鉴从地图进入。
- 每个短任务默认覆盖 5 个不同单词；新词默认最多 3 个，有长词时减少到 1～2 个。
- 每个词从示范、搭建、补全逐渐走向独立拼写；熟词可以跳过前面阶段。
- 本地单孩子档案起步；支持导出和导入备份，手机和平板自动同步作为后续工作。
- 本稿中的数量、经验和复习间隔都是可调整的初始规则，不代表已被验证的最优值。

课本出版社、版次、年级上下册及词表教学要求需根据实物或可信教材材料核对；不从年级名称推断版本。现有三年级数据和新增四年级数据均需经过相同核对后才能作为正式内容发布。

## 2. 一次完整使用流程

首次使用：家长确认课本及当前进度 → 孩子挑伙伴并取名 → 一道不计测验成绩的互动教学 → 进入当前单元 → 完成首个短任务 → 地图发生变化、领取第一件装饰 → 回营地。

日常使用：打开地图 → 继续未完成任务或开始今天推荐的短任务 → 完成学习与穿插复习 → 查看具体进步、获得伙伴成长 → 选择休息或进入挑战场。

回访：地图上的旧地点出现小任务 → 复习已学单词 → 根据这次独立拼写结果安排后续复习。

产品内的一次“任务”包含若干练习，不把一道题称为一个关卡。地图地点、任务和单词三个层级的文案要保持一致。

## 3. 页面与导航

| 页面 | 核心内容 | 主要操作 | 关键状态 |
| --- | --- | --- | --- |
| 家长首次设置 | 教材、册次、学到的单元、当前学习范围 | 确认范围 | 未选择、资料缺失、已确认 |
| 伙伴选择 | 三只伙伴、名字、简单性格介绍 | 选定并出发 | 未选、已选、恢复已有伙伴 |
| 冒险地图 | 六个连贯区域、伙伴位置、今日任务、继续学习 | 开始或继续 | 未开放、可探索、进行中、故事已完成、可回访 |
| 任务介绍面板 | 一句话目标、不同词数、新旧词构成 | 出发 | 新任务、恢复任务 |
| 学习页面 | 当前题目、字母操作、发音和帮助、任务进度 | 拼写与提交 | 示范、作答、纠正、完成、暂放 |
| 任务结算 | 独立完成、帮助完成、留待再练、伙伴成长 | 回营地 | 完整完成、提前结束、恢复结算 |
| 伙伴营地 | 伙伴形态、已获装饰、记忆日记 | 互动或换装 | 初始、成长、可选奖励 |
| 挑战场 | 可挑战词数、5 / 10 词选项、准备说明 | 开始挑战 | 无词、热身、5 词、10 词 |
| 单词图鉴 | 已接触的词、学习状态、点读 | 看词或练习 | 未认识、练过、独立拼过、较稳固、需要再练 |
| 家长区 | 教材范围、掌握记录、声音和显示、备份 | 设置或查看 | 正常、导入预览、存储异常 |

### 地图首页

- 顶部：伙伴头像与名字、当前册次、家长入口。
- 中部：地图和一个明确的当前任务。首次打开定位到正在学的区域，无需从第一单元滚动寻找。
- 主要按钮始终只有一个：有未完成任务时显示“继续探险”，否则显示“出发，去找 5 个单词”。
- 次要信息：当前 Unit、故事地点进度、可回访地点；详细学习统计放在图鉴与家长区。
- 底部：地图、伙伴、挑战三个带文字的入口。进入学习后收起全局导航。
- 拖动或滑动地图用于浏览；“回到伙伴位置”能快速定位。提供单元列表形式的替代入口。

### 任务介绍

用半屏面板说明“要去哪、要做什么、有几个不同的词”，例如“帮伙伴修好小桥：认识 3 个新词，再试 2 个老朋友”。

不预先展示本次回忆题的英文答案。已知任务长度有限，但完成时间按孩子操作变化，不显示倒计时。

### 任务结算

示例：“今天和团团练了 5 个词：3 个自己拼出，2 个在帮助下完成。”这里的独立完成限定为本次出现过合格的独立作答，不等于长期掌握。

- 只用一句具体进步作为亮点，如“apple 上次需要提示，这次自己拼出来了”。
- 伙伴获得经验，地图播放短暂变化，满足条件时让孩子选择装饰。
- 主操作是“回营地”；“再来一场 5 词挑战”为次操作，孩子主动选择后才开始。
- 提前结束也展示已完成的部分与保留的进度；不得虚报整项任务完成。
- 同一个任务结算只执行一次。刷新和重复点击不会重新发奖励。

## 4. 手机和平板操作规格

### 页面布局

学习页从上到下分为：退出和任务进度 → 单词情境、中文与发音 → 拼写区域 → 帮助或纠错 → 字母键盘与提交。

- 手机竖屏采用单列。屏幕较矮时先压缩装饰、缩小情境图占用，确保答案、修改和提交可用。
- 平板竖屏沿用相同结构并限制最大内容宽度；横屏可以情境和伙伴在左、拼写与键盘在右。
- 横竖屏切换保留输入、作答阶段和任务状态，不重新抽题。
- 页面适配安全区域、浏览器顶部底部工具栏变化以及系统字体放大。
- 字母和答案是视觉中心。伙伴在题目旁边安静陪伴，反馈动作短，动画可减少。

### 拼写输入

- 新手搭建题可用有限字母块；不要求拖拽，点一下就能放置，点已放的块可取回。
- 独立拼写题使用固定 A–Z 全字母键盘，不提供仅含答案字母的池子。
- 手机采用固定六列、按字母顺序排列，基本按键触控区域至少 44 × 44 CSS 像素；平板沿用相同顺序。
- 重复字母可以重复点击，不会像有限字母池一样用完消失。
- 提供清晰的退格、选择位置修改和提交；提交前的自行修改不记作错误。
- 不因点击一个错误字母立即打断孩子。提交完整尝试后再提供反馈。
- 英文采用清晰易辨认字体，正文、答案字母、提示分别设置适合移动端的字号；重点验证 b/d/p/q、I/l 的可辨认性。
- 长词不能将连续单词随意折成几行孤立字母。选择可容纳的文字输入表现；短语按词分组，必要时自然换行。
- 默认训练字母拼写。大小写、空格、连字符等要求由题目元数据明确：初版可预置词组分隔符，对字母正确但大小写不符作温和提醒，不默默混同为“全部书写要求已掌握”。
- 支持外接实体键盘作为兼容能力，但完整核心流程无需实体键盘。

### 声音

- 初次主动操作后启用发音；能随时点“再听一次”，重听不降低拼写评价。
- 发音、反馈音效分开开关，记住设置。新声音播放时终止上一条，避免叠音。
- 已加载内容没有可用音频时显示中文或情境并允许继续，听音题降级为看中文拼写；不把音频故障归为孩子错误。这不等于首版支持断网首次打开或完整离线资源包。
- 点读和跟读不自动等于发音掌握。首版记录听过或自愿跟读，不输出未经测量的口语分数。

## 5. 每个词怎样学会

| 练习类型 | 展示与输入 | 结果含义 | 后续 |
| --- | --- | --- | --- |
| 认识 | 中文、合适图片或短情境、完整英文、读音 | 接触过，尚未进入挑战池 | 跟着搭建或孩子主动试拼 |
| 示范搭建 | 保留正确范例，点字母或经校对的字母块 | 完成后记为练过 | 稍后补全或试拼 |
| 补全 | 显示部分正确字母，让孩子补缺失部分 | 有支持的拼写练习 | 根据表现减少提示 |
| 独立拼写 | 中文或发音、完整 A–Z 键盘，不显示拼写范例 | 首次提交正确才可计为本轮独立成功 | 安排隔后复习 |
| 温和纠错 | 显示差异、正确形式和读音，引导孩子修正 | 帮助下完成 | 间隔其他题后再试或下次再练 |

### 提示与纠错

帮助分三级：重听或情境线索 → 提示一个关键字母/字母组合 → 展示范例并带着搭建。

- 重听读音不会暴露字母，不降低“独立拼写”标记。
- 一旦展示拼写答案或完成部分字母，本次结果记为有帮助。
- 首次提交错误后，即使自己改对，也记录这次需要纠正；后续新的独立题可以重新提供能力证据。
- 第一处错误指出具体差异，如“这里少了一个 p”。避免整屏红色、长时间晃动或否定人格的评价。
- 同一题连续两次提交错误后主动展示更强帮助，并提供“先放一放”。
- 每个困难词本任务最多安排一次新的独立回忆机会；仍困难就保留到后续，避免无限原地重试。
- 不按单词完成速度判断记忆好坏，操作慢或停下来思考不降级。
- 用于辅助的拼读、词块与图片必须与该词匹配。既有 syllables 不经审核不能直接当作准确的发音拆分。

### 首版词状态

| 学习状态 | 进入条件 | 挑战资格 |
| --- | --- | --- |
| 未接触 | 没有学习事件 | 无 |
| 认识过 | 看过内容或听过，但没有完成拼写练习 | 无 |
| 练过 | 完成一次手动拼写或示范搭建，允许使用帮助 | 有 |
| 独立拼过 | 一次没有字母提示、首次提交正确的独立题 | 有 |
| 较稳固 | 至少三个不同学习日各有一次独立正确，相邻有效成功至少间隔 24 小时 | 有 |
| 需要再练 | 之前练过，后续回忆出现错误或需要帮助 | 保留 |

“较稳固”是应用内的操作性标记，不宣称永久记住；后续仍会安排复习。

挑战资格是独立字段：一旦练过便保留，重新需要复习不会让孩子失去资格。家长停用单词时，当前出题范围会排除它，但保留历史记录。

每一次题目必须有独立 attemptId。相同单词隔几题再次出现时可以重新初始化界面；不能用“单词文字没变化”作为跳过初始化的理由。

## 6. 短任务与复习安排

### 组题规则

- 默认 5 个不同目标词。常规任务优先 2 个到期或较弱的旧词，加最多 3 个新词。
- 无新词时全部复习；没有旧词时可从少量新词开始，不为了凑数强推 5 个新词。
- 新词较长或为词组时，新词数减至 1～2 个，并用熟词形成轻松开场。
- 已会的词先独立拼；新词先示范。孩子可以主动点“我想自己试试”。
- 同词再次出现尽量间隔至少两道其他词的题；词数不足时移到下一次学习，不伪装成间隔复习。
- 一次任务默认最多 12 次作答提交，包括修正提交；达到上限时允许结算，未完成的目标保留进度。5 / 10 词挑战另用自己的有限流程。
- 约五分钟是体验预算，不是倒计时、硬性合格线或经验加成条件。
- 孩子可暂停、保存并回地图；完成过的词和已确定的学习结果保留。

### 复习规则

所有练过的词都纳入复习，不限于错词。

初始可调规则：当天穿插一次 → 次日 → 上次有效回忆后 3 天 → 7 天 → 14 天 → 30 天；帮助下完成或回忆错误时缩短到下一次学习/次日，保留历史，不把成长清零。

- 当天重复答对不连续提升跨日复习阶段。
- 到期时间由真实的独立回忆结果推进；只看了一遍、点读、看答案修正不延长间隔。
- 如果没有其他词可供当天穿插，下一次独立检查移到以后。
- 缺席多日不把全部到期词一次压给孩子。按最需巩固、当前课内优先和适量熟词组成短任务。
- 首页用“小伙伴想再见见这几个单词”一类轻量邀请，不用醒目的欠账数字制造压力。
- 当前正在练的新词来自家长设定范围；历史已练词可以在复习中出现，除非家长明确停用。

### 有效的独立成功

同一次题的首次提交正确、没有展示拼写答案、使用完整字母键盘，才记录 independentCorrect。听发音可以作为出题方式或辅助，并不影响字母拼写结果。

选择题、有限字母池、补字母、看范例搭建和修正完成分别记录。它们有学习价值，但不能直接计入独立拼写掌握率。

## 7. 六单元连续地图

### 世界结构

一条从营地出发的连续路线连接六个区域。可用“启程草地、森林、溪流、山谷、云端、星光灯塔”作暂定美术框架；每个区域必须同时标明真实 Unit 和课本单元名。

美术主题是可替换配置，不能为了故事调整教材单元顺序。食物、动物、家庭、方位等具体情境按对应教材内容安排。

每个区域包括入口、若干故事地点和一个章节结束事件。短任务地点按有效词量动态划分，每个新词地点承载约 3～5 个不同词，并允许与旧词复习混编。

可复用故事模板：搭桥、找路、整理营地、点亮路灯、帮助朋友、准备野餐。首版用两三个完成度高的模板覆盖六区，主要改变背景、道具、任务文本和词表。

### 开放规则

- 默认“课本同步”：家长标记学到 Unit N，开放 Unit 1～N；孩子默认定位到 N，可直接学习当前范围。
- 未开放区域可以看见轮廓和名字，不通过消费或满分要求解锁。
- 当前章故事任务完成后提示下一章；同步模式下尚未教到的章节等待家长更新进度。
- 可选“自由探索”：完成当前章故事任务就开放下一章，家长同样可直接指定开放范围。
- 从 Unit 1 调到 Unit 4 只改变开放范围，不生成前三单元的虚假学习或掌握记录。
- 已完成的故事地点不因后续遗忘倒退或破坏；复习以附加回访任务呈现。

### 三种进度分别呈现

| 进度 | 含义 | 呈现 |
| --- | --- | --- |
| 地图开放 | 允许去哪里 | 路线、雾区和可进入区域 |
| 故事探索 | 哪些短任务完成过 | 修好的桥、亮起的营地、伙伴位置 |
| 单词记忆 | 独立拼过及跨日稳固情况 | 图鉴和家长报告 |

一个故事地点的全部目标词完成过有效练习，可以完成故事事件；不要求第一次全对，也不宣称全部词已掌握。提前结束只保存已练部分，地点等待后续完成。

## 8. 伙伴与奖励系统

### 伙伴设计

- 初始三选一，暂定小狐狸、小龙、团子鸟。名称和美术在视觉稿阶段确定。
- 选择后可取名，首版不要求账户注册。
- 每个伙伴三个成长阶段，保留可识别的核心特征，不用毫不相干的动物表示升级。
- 基本动作：等待、鼓励、提供帮助、庆祝、休息；反馈文本由已校对模板提供。
- 伙伴不影响题目公正性：不会因选不同物种而多给答案、减少要求或让题目变容易。
- 第一版允许在营地切换伙伴外观，保留共同冒险等级与装饰，不同时维护三份需要重复练习的经验账本。
- 喂食、摸摸和休息可以作为短暂互动，首次结算赠送点心即可体验；不设置随时间扣减的饥饿或亲密值。
- 第二、第三次进化后仍能收集章节纪念物；高等级不意味着单词已经掌握。

### 成长来源（待试用调参）

| 事件 | 初始奖励 | 限制与说明 |
| --- | --- | --- |
| 一个词在当天完成有效练习 | 2 点伙伴经验 | 同词每天一次；帮助完成也获得 |
| 首次独立拼出一个词 | 2 点经验 | 同词一次，另显示具体进步 |
| 一个到期词完成合格的跨日独立回忆 | 2 点经验 | 按该次复习检查一次，不能当天连续刷阶段 |
| 第一个短任务完整完成 | 选择一件欢迎装饰 | 一次；提前结束后继续完成也能获得 |
| 一个故事地点首次完成 | 地图变化和纪念贴纸 | 同地点一次，无额外模式计分 |
| 一个章节故事完成 | 选择一件主题装饰 | 同章节一次 |
| 第一次完成 5 / 10 词挑战 | 对应纪念章 | 每种首次一次，不用满分作为条件 |

挑战和普通学习共用同一套单词事件奖励；挑战不再另外乘以经验倍数，避免同一份学习行为重复发奖。

初始等级门槛可使用累计经验 0、20、50、90、140、200；第二级产生一个立即可见的小变化，第三级和第六级对应形态成长。数字是试用起点，需结合实际任务长度和奖励触发记录调整。

奖励领取会生成唯一 rewardEventId。先保存已发奖励，再展示动画；恢复任务不会重复领取。

### 让孩子有选择

- 首次选伙伴、取名。
- 已开放区域可以自主回访，主入口给一个清晰推荐。
- 困难时可以请求帮助或暂放。
- 章节装饰二选一；未选的装饰可以在后续正常里程碑中获得，不要求限时抢领。
- 选择 5 / 10 词挑战，或学完后回营地。

奖励美术与记忆日记显示“我们做到了什么”。首版不引入金币商店、随机抽卡、宠物战力对比或排名系统。

## 9. 5 / 10 词挑战场

### 词池

当前册次 + 已启用 + 完成过有效拼写练习，是进入词池的条件。只看过或听过不算；使用提示后完成算。

教材要求只认读的词，默认不进入拼写挑战池；若家长明确增加拼写目标并实际练习后，可以进入。

按学习项目去重。不同单元出现相同拼写且目标一致时，一局只出一次；不同含义或不同拼写要求的学习记录不能未经判断直接合并。

### 入口状态

| 词池数量 | 入口表现 |
| --- | --- |
| 0 | “先带伙伴认识几个单词吧”，可直接进入推荐任务 |
| 1～4 | 提供实际数量的热身，如“3 词热身” |
| 5～9 | 开放 5 词挑战，说明练到 10 个词可开启长挑战 |
| 10 及以上 | 默认选择 5 词，可主动选择 10 词 |

### 局内规则

- 抽取不同词，兼顾熟悉、最近练过和需要巩固；不加入新词，不为凑数重复词。
- 首版常规挑战以看中文独立拼写为默认，允许点读。语音正常时可单独选择听音挑战。
- 每词首次进入先给独立尝试；需要帮助就转为支持完成并记录。
- 每个词最多两次错误提交，之后带着修正或暂放；同一局不无限追加失败题。
- 5 词对应五个路线标记，10 词可分成前后两个五词段，中间允许保存离开。
- 默认不计时、不掉血、不淘汰。答错保留已完成路线，修正后伙伴继续前进。
- 页面固定显示“第 2 / 5 个词”；帮助结果影响学习记录，不中断挑战资格。
- 结算分独立、帮助、暂放三类。暂放词进入后续推荐，不自动启动加练。
- 整局“完成”要求所有词有完成结果；包含暂放时展示“本次探索结束”，保留未完成项，不发首次完整挑战纪念章。
- 退出、刷新和设备旋转可恢复；重复查看结算不能重复增加次数或奖励。

普通学习与挑战结果使用同一记忆更新规则。合格的挑战独立答对可以完成到期复习，不让孩子随后再被同一复习任务要求重复一次。

## 10. 课本与家长区

### 教材选择

明确展示出版社、教材系列、版本信息、年级、上下册。先接入一套核实完的教材，其余内容经过同样校对后再开放。

每个词保存：稳定 ID、课本 ID、单元、英文、该课含义、教学目标、页码（有据时）、图片或情境、可用音频、校对过的字母组合、答案规则、排序。

- 区分要求拼写、认读和词组；教材的黑体、星号标记必须按该版说明解释，不能直接将“黑体”一概转换为“必须默写”。
- 保留课内含义，避免把字典全部释义一次堆给孩子。
- 抽象词采用短场景或对比插图，新增词没有合适图片时使用文字情境，不随机匹配 Emoji。
- `phonetic`、`page`、`source` 等字段允许明确为空，不能编造内容。
- 家长可选择本周范围、启停词；批量导入作为后续效率功能，首版先把已有内容与少量手动维护做好。

### 家长报告

展示：本周有效练习天数、练过的不同词数、独立拼过的词数、跨日较稳固词数、当前最值得再练的一小组词。

- 每个“独立”“较稳固”标签都能看见定义与最近记录。
- 学习日必须有有效练习事件，仅打开首页不计入。
- 有效学习时长排除退后台和长时间闲置，只供家长参考，不参与等级、成就或能力判断。
- 不用累计点击次数表示会了多少词；不把有限字母池的正确率混进独立拼写正确率。
- 家长可偶尔在纸上检查少量词，区分屏幕拼写和实际默写表现；纸上结果单独标为家长录入。

### 多设备与备份

首版每个浏览器保存一份本地档案。手机和平板自动同步需要账号与远端存储，不在首版默认能力中。

- 提供导出、导入、数据格式版本和导入预览。
- 首版导入按“替换本机档案”明确处理，先保存本机备份并确认，不自动合并两套可能重复的奖励和学习记录。
- 伙伴及共同成长跨课本保留；词状态、题目进度与教材范围按课本区分。
- 明确显示未成功保存的情况，允许导出当前有效数据。不能静默丢失后继续声称已保存。
- 重置仅处理本应用指定数据，需明确确认，不调用无差别的 localStorage.clear()。

## 11. 视觉和内容资源

首版资源建议：三种伙伴 × 三个成长阶段；五类简短反馈动作可由基础姿态和轻动画复用；六区地图背景与路线；约十二件轻量装饰；六件章节纪念物；一套统一图标与按钮。

前期先做一个区域和一个伙伴的完整视觉样例，验证字母清晰、角色可识别、地图推进可理解，再批量制作其余资源。

每个关卡的学习内容在中央，剧情只占一句话。连续正确时反馈更简短；每次答对不播放长动画、不弹多层奖杯提示。成长动画安排在结算，避免遮住题目。

手机优先验证：360 / 390 / 430 像素宽，以及 320 像素窄屏兼容；平板验证 768 / 820 像素竖屏和相应横屏。上述是布局验收尺寸，不代表固定支持的机型列表。

触控重点检查：容易点中、改字不费力、页面不横向溢出、手指不被要求精确拖拽、字号放大后能完成任务、音频加载时仍有明确状态。

## 12. 数据和程序如何落地

### 数据对象

| 对象 | 关键字段 | 作用 |
| --- | --- | --- |
| LearnerProfile | id、partner、name、xp、cosmetics、settings | 孩子、伙伴及跨课本成长 |
| Book / Unit / Word | 稳定 ID、版次、单元、教学目标、内容、答案规则 | 正确的教材内容 |
| CurriculumProgress | bookId、schoolUnit、weeklyRange、unlockMode | 教学范围与地图开放 |
| WordProgress | learnerId、bookId、wordId、introducedAt、practicedAt、challengeEligible、independentSuccesses、reviewStage、dueAt | 逐词学习记录 |
| Attempt | attemptId、sessionId、wordId、exerciseType、hintLevel、firstSubmission、result、timestamp | 区分真实独立作答和帮助完成 |
| Session | sessionId、mode、targetWords、queue、currentAttempt、draftAnswer、results、status | 可恢复的短任务和挑战 |
| MapProgress | bookId、chapterId、locationId、completedTargets、storyCompleted | 持久的故事进度 |
| RewardEvent | rewardEventId、sourceEventId、type、amount、claimedAt | 避免重复奖励 |

以版本化存储对象和统一读写接口起步；事件更新保持一致、可恢复，后续需要云同步时可更换存储实现。具体采用 localStorage 或 IndexedDB 在实现时按记录量和持久化要求决定。

一次提交形成统一事件，再更新逐词记录、复习日期、任务结果、地图与奖励。页面只展示和发起用户操作，不让多个页面分别递增全局分数。

进度在确定结果时立即保存，输入草稿在暂停或适当的防抖时保存；切后台、刷新后恢复原 sessionId。对重复 attemptId / rewardEventId 做去重，不能仅依赖按钮禁用。

### 旧数据迁移

- 迁移前保留可恢复备份，不覆盖用户手动内容。
- 旧总分没有逐词独立作答证据，不能直接转换成单词掌握状态。
- 已有错词记录可以映射为练过/需要再练；有明确逐词练习证据的记录才能授予挑战资格。
- 对只有总分的历史可保留旧纪念记录并赠送固定欢迎装饰，新的成长从清楚的规则开始。
- 旧版不能确认的学习天数、速度成就不作为新规则证据。
- 当前工作区已有未跟踪的四年级词表和教材图片，本次产品设计不修改；后续开发需保护并核对其来源和导入状态。

## 13. 开发顺序与首版范围

### A. 建立可验证的学习流程

先完成一套教材中的少量词、完整字母键盘、搭建/补全/独立拼写、帮助和纠错、逐词记录、任务恢复与结算。用一只占位伙伴承接反馈，打通一条从学习到跨日复习的流程。

验收结果：同一个词使用帮助和独立拼写得到不同的学习记录；刷新不丢任务，重复点击不重计分；手机上能轻松修改和提交。

### B. 把地图、伙伴和奖励接入同一流程

先做一个区域的故事地点、伙伴成长与一套装饰选择，再扩成六区和三伙伴。接入教学进度直达、回访任务、图鉴、5 / 10 词挑战。

验收结果：孩子能从首页找到今天做什么，完成任务后地图和伙伴发生变化；家长可直接开放当前单元；挑战只使用练过的词。

### C. 完成内容与移动端交付

核对正式教材，完善听音降级、声音开关、横竖屏、后台恢复、数据备份和家长报告；在真实手机和平板上试用。

首版交付包括：一套核实的完整教材、六区地图、三选一轻量伙伴、短任务学习、全部练过词的复习、挑战场、图鉴、家长范围设置和本地备份。

后续候选包括：手机平板自动同步、多个孩子独立档案、更多教材、批量导入、安装到主屏及离线资源包、更多剧情或伙伴。口语评分需单独评估，不是首版拼写体验的依赖。

## 14. 验收清单

| 场景 | 预期结果 |
| --- | --- |
| 首次进入 | 家长确定范围后，孩子可完成伙伴选择和首题，无需注册 |
| 家长将进度改到 Unit 4 | 能直接进入第四区；前三单元不自动标成学过 |
| 只打开词卡或播放发音 | 不进入拼写挑战池，不发有效练习奖励 |
| 看范例完成手动搭建 | 进入挑战池，记录为练过，未计为独立掌握 |
| 全键盘第一次提交正确 | 记录独立成功，安排后续复习 |
| 看过字母提示后拼对 | 获得有效练习奖励，但不记独立成功 |
| 首次提交错误后修正 | 记录纠正完成，之后新题可以重新独立尝试 |
| 同一天反复拼同一个词 | 不无限累积逐词日奖励，不推进跨日稳固阶段 |
| 连续遇到困难 | 提供具体帮助、有限重试和暂放，任务不会无限延长 |
| 词池只有 3 个 | 只提供真实的 3 词热身，不补入新词 |
| 词池达到 10 个 | 提供 5 / 10 词，单局无重复目标词 |
| 学过的词重新出错 | 安排再练，保留挑战资格、地图成果和伙伴成长 |
| 普通任务提前结束 | 保存已完成部分和实际奖励，不标整地点完成 |
| 刷新、旋转、切后台再回来 | 恢复题目、答案草稿和结果，奖励不重复 |
| 已加载页面断网或音频失败 | 有明确反馈，可使用已加载的文字支持继续核心拼写 |
| 页面开着但没操作 | 不计有效学习天数，不生成速度或学习里程碑 |
| 切换课本或伙伴 | 词记录按册隔离，共同成长按孩子保留 |
| 手机窄屏及字体放大 | 主要控件可用，字母可辨认，不横向溢出 |
| 导出再导入 | 伙伴、逐词记录、地图和未完成任务一致 |

## 15. 试用怎样判断方向有效

先通过短期家庭试用观察方向，不能用一个孩子的一周表现宣称普遍效果。

- 主动性：孩子是否在没有提醒时提出开始；哪些选择最常被使用。
- 挫折体验：卡住之后是否继续，是否能自己找到帮助和修改；退出发生在哪里。
- 拼写变化：独立首次正确的词数、跨日仍能拼出的词数，避免把重复作答次数作为掌握量。
- 实际迁移：从练过的词中少量抽取纸上默写，和游戏内记录对照，不把屏幕操作熟练误当作书面拼写掌握。
- 体验长度：短任务实际耗时、遇到长词时的负担、结算是否有自然结束感。
- 宠物作用：是否记得伙伴名字、关心地图变化，能否在短互动后自然开始学习。

数值调整优先级：单次新词量 → 提示撤除速度 → 错词重现时机 → 任务长度 → 奖励频率。先确认学习过程可完成且有记忆进步，再扩展故事与装饰数量。

## 16. 设计依据与适用范围

- [IES：学习与复习安排指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) 支持间隔学习和主动提取等原则；本稿的具体间隔与次数是产品初始参数。
- [IES：基础读写教学指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/21) 提供声音与字母、单词构建等教学参考；应用到中国儿童英语课本词汇时仍需内容适配和实际试用。
- [自我决定理论：教育中的学习动机](https://selfdeterminationtheory.org/topics/application-education/) 为有意义的选择、能力进步与温暖支持提供理论参考；不能据此宣称某只宠物或经验数值必然提升兴趣。

实施前剩余内容选择主要是正式教材版次、伙伴美术和首个故事区域；设备、主要学习目标、地图结构和挑战资格已经明确，可据本稿制作原型与拆分开发任务。
